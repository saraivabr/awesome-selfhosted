# Awesome Selfhosted - Software Não-Livre

**O software listado aqui não atende à definição de [Software Livre](https://pt.wikipedia.org/wiki/Software_livre)**. Ele implementa seu próprio licenciamento com restrições e concessões que você deve verificar em cada caso. As restrições podem incluir limites no uso permitido do software, acesso ao código-fonte, modificação e redistribuição adicional. Este software pode, portanto, conter recursos anti-liberdade do usuário, tais como, mas não limitado a: backdoors, lock-in do usuário, envio de dados pessoais para terceiros.
